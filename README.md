## 🚀 Projects

### [Vendor Invoice Intelligence System: Freight Prediction & Invoice Risk Flagging](https://github.com/mayank864/predictive-invoice-flagging-ml-mern)
*Full-Stack ML Application | Python, Scikit-learn, FastAPI, React, Tailwind CSS* | [Live Demo](https://predictive-invoice-flagging-ml-mern.vercel.app/)
* Developed an end-to-end ML system featuring a Random Forest Regressor for freight cost prediction and a GridSearchCV-tuned Classifier for invoice risk flagging.
* Achieved high predictive accuracy (0.97 R² for freight costs, 0.89 F1-Score for invoice risk) by cleaning and preparing raw data from a large 400MB+ database using SQL aggregations and statistical validation.
* Implemented a production REST API using FastAPI and Pydantic, enabling real-time, validated model inference via Joblib serialization.
* Deployed a full-stack cloud application (React/Tailwind frontend on Vercel, API on Render), providing users with an intuitive dashboard for instant freight estimates and explainable risk flags.

### [EDA-Vendor Performance & Inventory Analytics](https://github.com/mayank864/eda-vendor-performance-analysis-sql-python-powerbi)
*Python, SQL, Power BI, Excel*
* Architected an automated ETL pipeline using Python (sqlalchemy, pandas) and SQLite to clean, process, and ingest 15M+ raw transactional records.
* Used SQL to combine data from multiple tables and calculate key metrics like Gross Profit, Stock Turnover, and Profit Margins.
* Built an interactive Power BI dashboard tracking $441.41M in sales, $134.07M in gross profit, and $2.71M in stagnant capital.
* Conducted statistical analysis revealing a 72% unit cost reduction via bulk purchasing and identified 198 high-margin, low-sales brands for targeted marketing optimization.

### [Bank Loan Risk & Performance Analytics](https://github.com/mayank864/bank-loan-portfolio-analysis-sql-pyhton-powerbi-excel)
*Python, SQL, Power BI, Excel*
* Performed exploratory data analysis and data processing (handling missing values, data type formatting) using Python and Excel to prepare a high-quality financial dataset of over 38.6K loan applications.
* Implemented relational data queries and aggregations in SQL to extract core banking metrics, accurately tracking Month-over-Month (MoM) growth, an average interest rate of 12.0%, and an average DTI of 13.3%.
* Designed an interactive Power BI dashboard with dynamic KPIs, slicers, and trend analysis to visualize portfolio health, successfully segmenting $435.8M in funded capital into Good (86.2%) vs. Bad (13.8%) loans to support strategic, data-driven decision-making.

### [Blinkit Sales & Retail Analytics](https://github.com/mayank864/blinkit-analysis-python-sql-powerbi-excel)
*Python, SQL, Power BI, Excel*
* Processed and cleaned 8,500+ transactional records using Python (Pandas) and SQL to eliminate data discrepancies and calculate core KPIs ($1.20M Total Sales, $141 AOV, 3.9/5 Rating).
* Performed exploratory data analysis across 16 product types and 4 outlet formats to uncover inventory visibility patterns and customer purchasing trends.
* Architected an interactive Power BI dashboard with dynamic filtering, enabling stakeholders to analyze sales performance across store sizes, establishment years, and location tiers.
* Delivered actionable insights identifying Tier 3 markets ($472K revenue) and Medium-sized Supermarkets as primary growth drivers for quick-commerce expansion.
